# Psykologille.fi

Staattinen yhden sivun verkkosivusto, joka on toteutettu semanttisella HTML:llä,
CSS:llä ja pienellä määrällä JavaScriptiä. Sivusto ei käytä riippuvuuksia,
paketinhallintaa tai build-vaihetta.

Toteutus sisältää responsiivisen ulkoasun, paikalliset kuva- ja fonttiresurssit,
Schema.org-rakenteisen datan, Open Graph -metatiedot, sivustokuvakkeet sekä
hakukoneiden perustiedostot.

Paikallinen esikatselu:

```sh
python3 -m http.server 8000
```
